## Быстрый старт

**Пользователю:** откройте [USER_GUIDE.md](USER_GUIDE.md), раздел «Настройка при первом
запуске». Порядок шагов обязателен — почта, нейросеть, Вики, подраздел, режим публикации.

**Разработчику:** откройте [TECHNICAL.md](TECHNICAL.md), разделы 5–10 (фоновая работа,
почта, промпты, выбор промпта, Вики, нейросеть) и 13 (дефекты).

**Планируете перенос в HRM:** [HRM_IMPLEMENTATION.md](HRM_IMPLEMENTATION.md) целиком —
это готовый технический разбор с промптами дословно.

## Три факта, о которых стоит знать сразу

1. **Оригинал конспекта сохраняется рядом с протоколом.** В ветке «Конспекты» лежит ровно
   то, что было в письме, без правок. Все изменения — только в ветке «Протоколы».

2. **Шаблон выбирается по началу темы письма.** Тема «Совет директоров — 01.09» подойдёт
   к промпту «Совет директоров», а «Оперативка по Совете директоров» — нет.

3. **В наборе промптов есть дефекты.** Два из трёх — полные копии друг друга, третий
   обрывается на полуслове и не содержит указаний на формат вывода. Подробности
   в [TECHNICAL.md](TECHNICAL.md), раздел 13.

## Состояние кода

Документация описывает состояние на 30.09.2026: коммит `23d11b3`, незакоммиченные правки
в `bot.py` и `prompts.json`.

Найдено 9 дефектов, из них один латентный, но опасный: блок выбора промпта
(`bot.py:1598-1632`) из-за лишнего отступа оказался внутри `if progress:`. Файл
компилируется без ошибок, все текущие вызовы проходят с непустым `progress`, поэтому
дефект не проявляется — но любой вызов без прогресса получит `UnboundLocalError`.

Тесты не выполняются: `tests/test_access.py:181` вызывает `sys.exit()` на уровне модуля,
из-за чего `pytest` прерывает коллекцию.
